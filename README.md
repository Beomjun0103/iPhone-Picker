# iPhone picker

2007년 첫 아이폰부터 2025년 아이폰 17 Pro까지 **51기종**, 그리고 갤럭시 **19기종**을
크기 · 무게 · 두께 · 카메라 · 칩 · 배터리로 비교하는 웹사이트입니다.

**👉 https://beomjun0103.github.io/iPhone-Picker/**

만든 사람 · Beomjun

## 내용 고치는 법

1. 이 저장소에서 **`Add file` → `Upload files`**
2. 새 `index.html` 을 끌어다 놓기 (같은 이름이라 덮어써집니다)
3. **`Commit changes`**
4. 1~2분 뒤 사이트에 반영됩니다

바로 안 바뀌면 `Cmd + Shift + R` 로 강력 새로고침 하세요.

## 구조

스크롤 한 장짜리가 아니라, **오른쪽 위 메뉴에서 고른 화면 하나만** 보여 줍니다.
메뉴는 3×4 격자라 폰에서도 잘리지 않습니다.
주소창의 `#quiz`, `#siri` 같은 해시로 화면을 관리하므로 **뒤로 가기 버튼도 그대로 동작**하고,
특정 화면 링크를 그대로 공유할 수도 있습니다.

## 기술 메모

- 외부 라이브러리 **없습니다**. HTML 파일 하나에 CSS·JS가 전부 들어 있습니다
- 폰트: 애플 기기에서는 시스템 폰트(SF Pro / Apple SD Gothic Neo), 그 외에는 IBM Plex Sans KR
- 다크모드는 브라우저 설정을 따라 자동으로 바뀝니다
- 폰 일러스트는 이미지가 아니라 **코드로 그린 SVG**라 아무리 키워도 깨지지 않습니다 (저작권 문제도 없습니다)
- 피드백은 클립보드 복사 방식이라 **로그인 없이 누구나** 쓸 수 있습니다

## 추천은 이렇게 계산합니다

여섯 질문의 답에 가중치를 매겨 51기종 전부에 점수를 냅니다.
어느 한 질문이 나머지를 눌러 버리지 않도록 항목별 영향 폭을 비슷하게 맞췄고,
1,620가지 조합을 전부 돌려서 **35종**이 1등으로 나오는 것을 확인했습니다.
한 기종이 차지하는 비율은 최대 11.8%입니다.

## 자료 출처 / 주의

- 스펙은 애플 · 삼성이 공식으로 밝힌 값 (화면 크기, 무게, 두께, 영상 재생 시간, mAh)
- 가격은 **한국 출시가** 기준 — 지금 시세와 다를 수 있습니다. 1세대와 3G는 한국 미출시라 미국 가격입니다
- 애플은 mAh를, 삼성은 영상 재생 시간을 공개하지 않아 **배터리는 브랜드 간 직접 비교가 불가능합니다**
- 추천 결과는 답변에 점수를 매긴 계산값이라 참고용입니다
